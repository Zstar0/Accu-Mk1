# HPLC Native-Born — Slice 6 (M8: native status relay Mk1→IS, native retest auto check-in, native-born guards on uid-keyed paths) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native-born sample's receive / verify / publish reach the WordPress order stepper through IS without SENAITE; a retest order for a native-born original is auto checked-in natively (photo + remark copied from the original Mk1 row); every remaining SENAITE-uid-keyed path is guarded for native-born rows.

**Architecture:** Sample-tier status for native-born rows is written in exactly one place under mk1 authority — `workflow/engine.py::_write_status_if_authoritative` (receive via `drive_sample_touchpoint(..., "receive")`, verify via the side-by-side cascade edge `to_be_verified → verified`, publish via `_after_publish_native`). This slice adds ONE relay client `workflow/status_relay.py` and calls it from that writer (after the status is set, before commit, never-raise) when the sample is native-born and the new slug is `sample_received` / `verified` / `published`. The relay posts the shared contract to IS (`POST {INTEGRATION_SERVICE_URL}/explorer/samples/{id}/status`, `X-API-Key`), with a stable `event_id = f"mk1-{sample_id}-{transition}-{ordinal}"` (ordinal = number of prior `lims_sample_transitions` rows for that verb on the sample, so a retry re-sends the same id and IS de-duplicates) and `order_ref = lims_samples.client_order_number` ("WP-4242"). Outcome is recorded as a `LimsSubSampleEvent("native_status_relayed"|"native_status_relay_failed")`. Retest intake: new nullable column `lims_samples.retest_of_sample_id` filled from meta `RetestOfSampleId`; when meta `AutoCheckin` is true and the original is a native-born row that has been received, the S2S upsert route schedules `native_auto_checkin(sample_id)`, which copies the original's `receive_image` bytes (`fetch_photo` → `save_photo`) and its receive-time remark, then runs `_receive_native_phase` (which reaches the engine writer → relay). Guards: `_capture_parent_attachment_bg` resolves the row by `sample_id` when the uid lookup misses (callers pass the sample id too); `_refresh_parent_from_senaite` returns early for native-born rows (and the debug refresh route reports `native_born_no_senaite`); `is_event_stream.sync_once` skips native-born samples; `scripts/parity_sample_details.py` skips native-born rows.

**Tech Stack:** Python 3.11, FastAPI, SQLAlchemy 2, httpx, pytest (sqlite in-memory + StaticPool TestClient; the live-DB receive harness `tests/test_receive_native_first.py` for the check-in path).

## Global Constraints
- **Additive only; SENAITE-born byte-identical.** Every branch keyed on `is_native_born(row)` (`lims_analyses.hplc_native`). The SENAITE tee, `is_event_stream` for legacy rows, the worksheet relay, and the legacy receive path are untouched.
- **Relay never raises and never blocks a transaction on the network:** the engine writer records intent (`LimsSubSampleEvent("native_status_relay_pending", details={transition, event_id})`) in the same transaction and the HTTP call happens in a `BackgroundTasks`/threadpool step after commit where a request context exists, else synchronously with a 10 s timeout inside `try/except` (mirror `_notify_worksheet_assigned`). Outcome events: `native_status_relayed` / `native_status_relay_failed`. **Ruling:** no retry job in this slice (one attempt + a loud event; a `native_status_relay_failed` report row is the pre-flip watch item) — follow-up ticket.
- **Stable `event_id`** per `(sample_id, transition, ordinal)`.
- **One new column:** `lims_samples.retest_of_sample_id TEXT NULL` — `"ALTER TABLE lims_samples ADD COLUMN IF NOT EXISTS retest_of_sample_id TEXT"` appended immediately after the `'PB'` counter seed at the END of the migration list (`database.py` ~2390); no bindparams; model column `retest_of_sample_id: Mapped[Optional[str]] = mapped_column(Text, nullable=True)`.
- **Env:** reuse `INTEGRATION_SERVICE_URL` + `ACCU_MK1_API_KEY` exactly as `_notify_worksheet_assigned` does (`main.py:11377-11378`); never print values.
