# Endotoxin slice 3: Promote to Parent, per-result LOQ and LOD, unit-aware specs: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let analysts promote native endotoxin results from the 2 mL worksheet's Results box to the parent sample, with each result carrying its own LOQ and LOD, and judge every result against the spec row in its own unit so peptides can move to 350 EU per vial without touching bac water or older EU/mL results.

**Architecture:** Three nullable columns on `lims_analyses` (`loq`, `lod`, `lod_unit`) travel with a result through submit, promote, retest carry and reset. The sample page's promote route body moves into one shared service function that a new worksheet endpoint (`POST /worksheets/{id}/promote`) also calls, row by row, after re-checking eligibility from stored worksheet data; the browser sends the values the analyst sees. Spec uniqueness and `resolve_spec` gain the unit; the COA build prefers a result's own LOQ and passes it through the wire field coabuilder already reads, so coabuilder, WordPress and the Integration Service do not change.

**Tech Stack:** FastAPI + SQLAlchemy 2 (Postgres in prod, SQLite in unit tests), pydantic v2, pytest; React 19 + TypeScript + TanStack Query + the app's shadcn/Radix components, vitest + Testing Library; npm only.

**Spec:** `docs/superpowers/specs/2026-10-12-endo-slice3-promote-loq-design.md` (approved 2026-10-12). Read it before any task; section numbers below refer to it.

## Review Focus

1. **A vial retested after its reading was taken.** The live endotoxin row is now the retest row; promote must fill and promote that row (the current-row idiom), and the parent's earlier result is superseded through the retest path, never duplicated. Pinned in Task 5.
2. **The same rows promoted twice** (double click, two tabs, two analysts). The second request returns per-row "already promoted" or "the parent already holds a result", never a second parent row and never a 500 (a unique-index `IntegrityError` maps to a refusal). Pinned in Tasks 2 and 5.
3. **Unit spellings in stored data** (`"EU/Vial"`, `" EU/mL "`, a spec row with a NULL unit, a result with a NULL unit falling back to the service unit). The lookup normalizes and never judges a result against a row filed in another unit; where a service files no row in the result's unit, only a result in the service's catalog unit falls back to today's lookup (A.0 item 3). Pinned in Task 3.
4. **A promoted result later reset or un-promoted on the sample page.** Its LOQ and LOD are cleared with the value, so a regenerated COA can never print a stale "< LOQ". Pinned in Task 1.
5. **Stock and mixed worksheets.** No promote UI, and the endpoint refuses rows of a stock (1 mg/mL) worksheet with "promote is for 2 mL worksheets". Pinned in Tasks 5 and 7.

Create `backend/tests/test_result_limits.py`:

```python
"""Endo slice 3, Task 1: per-result LOQ / LOD on lims_analyses.

The three columns travel with the value (retest carry) and are cleared with it
(reset, both un-promote paths); a new retest row starts without them; the
amendment audit records them as JSON-safe values; every analysis payload,
including the registry re-type the mk1 sample page reads, declares them.

Spec: docs/superpowers/specs/2026-10-12-endo-slice3-promote-loq-design.md
sections 4 and 7; plan Review Focus 4. In-memory SQLite (`db_session`,
tests/conftest.py).
"""
from __future__ import annotations

import json

from sqlalchemy import inspect, select

from lims_analyses.service import (
    apply_transition,
    cascade_parent_retest_to_sources,
    list_analysis_change_events_for_parent,
    promote_to_parent,
    vial_source_retest,
)
from models import (
    AnalysisService,
    LimsAnalysis,
    LimsAnalysisTransition,
    LimsSample,
    LimsSubSample,
)

LIMITS = {"loq": 25.0, "lod": 0.05, "lod_unit": "EU/mL"}
CLEARED = {"loq": None, "lod": None, "lod_unit": None}


def _limits(obj) -> dict:
    return {"loq": obj.loq, "lod": obj.lod, "lod_unit": obj.lod_unit}


def _set_limits(row) -> None:
    row.loq, row.lod, row.lod_unit = LIMITS["loq"], LIMITS["lod"], LIMITS["lod_unit"]


def _endo_world(db):
    """A native endotoxin service, a parent with one vial, one unassigned vial row."""
    svc = AnalysisService(title="Endotoxin USP85 LAL", keyword="ENDOTOXIN-USP85LAL",
                          origin="mk1", unit="EU/mL")
    parent = LimsSample(sample_id="P-7001", external_lims_uid="uid-P-7001")
    db.add_all([svc, parent])
    db.flush()
    vial = LimsSubSample(parent_sample_pk=parent.id, external_lims_uid="uid-P-7001-S01",
                         sample_id="P-7001-S01", vial_sequence=1)
    db.add(vial)
    db.flush()
    row = LimsAnalysis(lims_sub_sample_pk=vial.id, analysis_service_id=svc.id,
                       keyword=svc.keyword, title=svc.title)
    db.add(row)
    db.commit()
    return svc, parent, row


def _promoted_parent_with_limits(db):
    """The vial result submitted and promoted; the parent row then carries the
    limits (Task 2 copies them at promote; set directly so this task stands alone)."""
    svc, parent, row = _endo_world(db)
    apply_transition(db, analysis_id=row.id, kind="submit", result_value="25")
    parent_row, _ = promote_to_parent(
        db, keyword=svc.keyword, result_value="25", result_unit="EU/vial",
        method_id=None, instrument_id=None,
        sources=[{"analysis_id": row.id, "contribution_kind": "chosen"}],
    )
    _set_limits(parent_row)
    db.commit()
    return svc, parent, row, parent_row


def _last_changed(db, analysis_id) -> dict:
    db.expire_all()   # read the stored details back, not the in-memory dict
    t = db.execute(
        select(LimsAnalysisTransition)
        .where(LimsAnalysisTransition.analysis_id == analysis_id)
        .order_by(LimsAnalysisTransition.id.desc()).limit(1)
    ).scalar_one()
    return t.details["changed"]


def test_columns_exist_and_start_empty(db_session):
    cols = {c["name"] for c in inspect(db_session.get_bind()).get_columns("lims_analyses")}
    assert {"loq", "lod", "lod_unit"} <= cols
    _svc, _parent, row = _endo_world(db_session)
    assert _limits(row) == CLEARED


def test_boot_migrations_add_the_columns_above_the_pinned_last_statement():
    from tests.test_hplc_native_schema import _captured
    stmts = _captured()
    for sql in ("ALTER TABLE lims_analyses ADD COLUMN IF NOT EXISTS loq DOUBLE PRECISION",
                "ALTER TABLE lims_analyses ADD COLUMN IF NOT EXISTS lod DOUBLE PRECISION",
                "ALTER TABLE lims_analyses ADD COLUMN IF NOT EXISTS lod_unit TEXT"):
        assert sql in stmts, sql
    assert stmts[-1] == "ALTER TABLE lims_samples ADD COLUMN IF NOT EXISTS retest_of_sample_id TEXT"


def test_reset_clears_the_limits_and_the_audit_records_them_as_json(db_session):
    _svc, _parent, row = _endo_world(db_session)
    apply_transition(db_session, analysis_id=row.id, kind="assign")
    row.result_value = "25"            # a draft, as the bench writes it
    _set_limits(row)
    db_session.commit()

    apply_transition(db_session, analysis_id=row.id, kind="reset")

    changed = _last_changed(db_session, row.id)
    assert _limits(db_session.get(LimsAnalysis, row.id)) == CLEARED
    assert changed["loq"] == {"before": 25.0, "after": None}
    assert changed["lod"] == {"before": 0.05, "after": None}
    assert changed["lod_unit"] == {"before": "EU/mL", "after": None}
    assert isinstance(changed["loq"]["before"], float)
    assert isinstance(changed["lod"]["before"], float)
    json.dumps(changed)                # the audit column must stay JSON-serializable


def test_reset_that_preserves_the_draft_keeps_the_limits(db_session):
    """A worksheet releasing its claim (preserve_draft) never owned the draft."""
    _svc, _parent, row = _endo_world(db_session)
    apply_transition(db_session, analysis_id=row.id, kind="assign")
    row.result_value = "25"
    _set_limits(row)
    db_session.commit()

    apply_transition(db_session, analysis_id=row.id, kind="reset", preserve_draft=True)

    db_session.refresh(row)
    assert row.result_value == "25" and _limits(row) == LIMITS


def test_a_new_retest_row_starts_without_limits(db_session):
    _svc, _parent, row = _endo_world(db_session)
    apply_transition(db_session, analysis_id=row.id, kind="submit", result_value="25")
    _set_limits(row)
    db_session.commit()

    new_row = apply_transition(db_session, analysis_id=row.id, kind="retest")

    assert _limits(new_row) == CLEARED
    db_session.refresh(row)
    assert _limits(row) == LIMITS      # the retested row keeps its history


def test_source_retest_unpromote_clears_the_parent_limits(db_session):

    its LOQ / LOD go with the value, so a regenerated COA cannot print a stale
    "< LOQ"."""
    _svc, _parent, row, parent_row = _promoted_parent_with_limits(db_session)

    vial_source_retest(db_session, analysis_id=row.id, user_id=None)

    changed = _last_changed(db_session, parent_row.id)
    parent_row = db_session.get(LimsAnalysis, parent_row.id)
    assert parent_row.review_state == "retracted" and parent_row.result_value is None
    assert _limits(parent_row) == CLEARED
```

```python
"""Promote to parent: the body of POST /api/lims-analyses/promote, shared with
the worksheet endpoint (endo slice 3, spec 2026-10-12 section 5.3 step 3).

run_promote resolves the parent target, runs service.promote_to_parent,

origin='mk1'), records how the tee went, then runs the side-by-side cascade.

always raised, so the sample page sees the same status and body as before.

SENAITE and slot resolution are reached through their module attributes

"""
from __future__ import annotations

import logging
from datetime import date
from typing import Any, Optional

from fastapi import BackgroundTasks
from sqlalchemy.orm import Session

from lims_analyses import senaite_writeback, service
from lims_analyses.schemas import AnalysisResponse, PromoteRequest, PromoteResponse, PromotionRow
from lims_analyses.senaite_writeback import SenaiteParentLineLocked, SenaiteWritebackError

logger = logging.getLogger(__name__)

# The code of a refusal whose HTTP body is a plain string; dict bodies carry
# their own "code".
_CODE_BY_STATUS = {400: "bad_request", 404: "not_found", 502: "senaite_writeback_failed"}


class PromoteError(Exception):
    """A promote refusal. `code` and `detail` are for callers that report per
    row (the worksheet endpoint); `status` and `body` are exactly the status
    and detail of the HTTPException the sample page's route raised before the
    move (a string, or a dict such as {"code", "message"})."""

    def __init__(self, code: str, status: int, detail: str, body: Any = None):
        super().__init__(detail)
        self.code = code
        self.status = status
        self.detail = detail
        self.body = detail if body is None else body


def _refusal(e: Exception) -> PromoteError:
    """promote_to_parent's exception as a PromoteError, through the route's own
    mapping (routes._handle_service_error) so status and body stay identical.
    An exception that mapping does not know is re-raised unchanged (a 500, as
    before)."""
    from lims_analyses.routes import _handle_service_error  # call time: routes imports this module

    http = _handle_service_error(e)
    if isinstance(http.detail, dict):
        message = http.detail.get("message") or str(e)
        return PromoteError(http.detail["code"], http.status_code, message, body=http.detail)
    return PromoteError(_CODE_BY_STATUS.get(http.status_code, "error"), http.status_code,
                        http.detail)


def _run_cascade(background_tasks: Optional[BackgroundTasks], parent_pk: Optional[int],
                 user_id: Optional[int]) -> None:
    """The side-by-side engine after a promote, as routes._schedule_sbs_cascade
    does it for the other analysis routes: post-response on the request's
    BackgroundTasks, or inline (the promote is already committed) for a caller
    outside a request. Never raises; run_cascades_bg opens its own session."""
    try:
        from workflow.engine import run_cascades_bg, shadow_enabled
        if not shadow_enabled() or parent_pk is None:
            return
        if background_tasks is not None:
            background_tasks.add_task(run_cascades_bg, parent_pk, user_id)
        else:
            run_cascades_bg(parent_pk, user_id)
    except Exception:
        logger.exception("sbs cascade scheduling failed (never-raise)")


def run_promote(
    db: Session,
    current_user,
    req: PromoteRequest,
    *,
    background_tasks: Optional[BackgroundTasks] = None,
    audit_reason: Optional[str] = None,
) -> PromoteResponse:
    """Promote req.sources to one parent-tier row and commit it.

    Raises PromoteError for every refusal (404 unknown source, 502 parent slot
    resolution, 400 / 404 validation, 409 parent row already exists). Before
    raising, the session is rolled back, so a caller's uncommitted writes in
    the same session (the worksheet's fill of the vial result) go with it: the
    fill and the promote land together or not at all. A failed commit is
    logged, rolled back and re-raised as is.

    audit_reason, when given, is appended to the reason of every transition
    row the promote writes ("promoted from worksheet WS-24 row 3").

    background_tasks is the request's when called from a route: the cascade
    is then scheduled post-response, as the route always did. Without it the
    cascade runs inline after the commit.
    """
    from models import AnalysisService, LimsAnalysis, LimsSample, LimsSubSample

    user_id = getattr(current_user, "id", None)

    # Resolve the parent SENAITE sample_id + parent-AR target keyword BEFORE
    # promoting, so per-substance vial keywords (PUR_<X>/QTY_<X>) land on the
    # parent's generic ANALYTE-{slot} line. Native keywords pass through
    # unchanged (no SENAITE read).
    first_src = db.get(LimsAnalysis, req.sources[0].analysis_id)
    if first_src is None:
        db.rollback()
        raise PromoteError("source_not_found", 404, "source analysis not found")
    if first_src.lims_sub_sample_pk is not None:
        _sub = db.get(LimsSubSample, first_src.lims_sub_sample_pk)
        _parent = db.get(LimsSample, _sub.parent_sample_pk) if _sub else None
    else:
        _parent = db.get(LimsSample, first_src.lims_sample_pk)
    parent_sample_id = _parent.sample_id if _parent else None

    # Native (origin='mk1') sources have no per-substance SENAITE translation
    # and no SENAITE keyword contract at all; the caller-supplied req.keyword
    # is advisory, not identity. Force promote_to_parent's native-identity
    # override (service-derived keyword/title/unit, service.py step 4c) to
    # fire by passing None through, instead of trusting a request string that
    # can drift or arrive empty. Detected off the FIRST SOURCE's service:
    # native keywords never match the PUR_/QTY_ per-substance regex, so
    # resolve_parent_analyte_target would be a no-op for them anyway; this
    # just skips the call and is explicit about why.
    _first_src_svc = db.get(AnalysisService, first_src.analysis_service_id)
    _first_src_is_native = _first_src_svc is not None and _first_src_svc.origin == "mk1"

    if _first_src_is_native:
        parent_keyword, parent_service_id, parent_title = None, None, None
    else:
        try:
            if parent_sample_id:
                parent_keyword, parent_service_id, parent_title = service.resolve_parent_analyte_target(
                    db, vial_keyword=req.keyword, parent_sample_id=parent_sample_id)
            else:
                parent_keyword, parent_service_id, parent_title = req.keyword, None, None
        except Exception as e:
            db.rollback()
            raise PromoteError("parent_slot_resolution_failed", 502,
                               f"parent slot resolution failed: {e}") from e

    try:
        parent_row, promotion_rows = service.promote_to_parent(
            db,
            keyword=req.keyword,
            result_value=req.result_value,
            result_unit=req.result_unit,
            method_id=req.method_id,
            instrument_id=req.instrument_id,
            sources=[s.model_dump() for s in req.sources],
            user_id=user_id,
            reason=req.reason,
            parent_keyword=parent_keyword,
            parent_analysis_service_id=parent_service_id,
            parent_title=parent_title,
            loq=req.loq,
            lod=req.lod,
            lod_unit=req.lod_unit,
            audit_reason=audit_reason,
            commit=False,
        )
    except Exception as e:
        # A unique-index IntegrityError on the parent insert (a second parent
        # row: double click, two tabs) leaves the session unusable until this
        # rollback; it maps to 409 parent_row_already_exists below.
        db.rollback()
        raise _refusal(e) from e

    # ── SENAITE write-back (fail-closed) ──────────────────────────────────────
    # parent_sample_id was derived above (one definition). If it could not be
    # resolved, fall back to the parent-tier row's sample_id label.
    if parent_sample_id is None:
        parent_sample_obj = db.get(LimsSample, parent_row.lims_sample_pk)
        parent_sample_id = parent_sample_obj.sample_id if parent_sample_obj else str(parent_row.lims_sample_pk)

    # Collect source-vial sample_id labels from sub-sample rows.
    vial_ids: list[str] = []
    for prom in promotion_rows:
        src_analysis = db.get(LimsAnalysis, prom.source_analysis_id)
        if src_analysis and src_analysis.lims_sub_sample_pk is not None:
            sub = db.get(LimsSubSample, src_analysis.lims_sub_sample_pk)
            if sub is not None:
                vial_ids.append(sub.sample_id)

    email = getattr(current_user, "email", None) or "unknown"
    remark = (
        f"Promoted from {', '.join(vial_ids) if vial_ids else '(unknown vials)'} "
        f"(Accu-Mk1) by {email} on {date.today().isoformat()}"
    )

    # ── Origin gate (native COA sections, spec 2) ─────────────────────────────
    # A service with origin='mk1' has no SENAITE representation: there is no
    # analysis line to write back to, so the Mk1-side commit IS the promotion.
    # Read origin from the service backing the PARENT row, never the vial row:
    # resolve_parent_analyte_target translates per-substance keywords, and its
    # notion of "native" (not PUR_/QTY_) is a different predicate from
    # origin='mk1'.
    _parent_svc = db.get(AnalysisService, parent_row.analysis_service_id)
    _skip_writeback = _parent_svc is not None and _parent_svc.origin == "mk1"

    # ── Accu-Mk1 writes FIRST (Handler ruling 2026-09-10) ────────────────────
    # Post read-independence Mk1 is the canonical tier: these rows are what
    # Sample Details and the COA wire read, and SENAITE's analysis line is the
    # mirror. Committing the mirror first and the source of truth second is
    # what allowed a lost Mk1 commit to strand a family with a verified SENAITE
    # line, no Mk1 promotion, and (because the lock map then read that mirror)
    # no Promote verb in the UI either (P-2553, P-2606; both needed a by-hand
    # replay of promote_to_parent against prod).
    #
    # So the local write is made durable BEFORE SENAITE is touched, and the
    # write-back becomes a tee that can fail without taking the promotion down
    # with it. A commit failure here means nothing was written anywhere, which
    # is a clean failure with no divergence to reconcile.
    try:
        db.commit()
    except Exception:
        logger.exception(
            "promote_commit_failed parent=%s keyword=%s: SENAITE was not called, "
            "nothing to reconcile",
            parent_sample_id, parent_row.keyword,
        )
        db.rollback()
        raise
    db.refresh(parent_row)
    for p in promotion_rows:
        db.refresh(p)

    # ── Tee to SENAITE (best effort; the promotion above already stands) ─────
    _sync_event: Optional[tuple] = None
    if not _skip_writeback:
        try:
            senaite_writeback.writeback_promotion(
                parent_sample_id,
                parent_row.keyword,        # parent ANALYTE-{slot} (was req.keyword)
                req.result_value,
                remark,
            )
        except SenaiteParentLineLocked as e:
            # Locked line (verified/published): SENAITE can never retract it,
            # so aborting here would dead-end every retest re-promote on a
            # senaite-origin family. Handler ruling 2026-08-30: the canonical
            # row is the certificate authority post read-independence, so
            # diverge deliberately: record it and promote natively.
            logger.warning(
                "senaite_promote_divergence parent=%s keyword=%s senaite_state=%s uid=%s "
                "(native promote proceeds, SENAITE line left as-is)",
                parent_sample_id, parent_row.keyword, e.state, e.uid,
            )
            _sync_event = ("senaite_line_diverged", {
                "keyword": parent_row.keyword,
                "senaite_state": e.state,
                "senaite_uid": e.uid,
                "reason": "promote over locked SENAITE line — canonical value takes control",
            })
        except SenaiteWritebackError as e:
            # Unreachable / refused / line missing. The promotion is already
            # committed, so this is the MIRROR falling behind, not lost work.
            # Recorded on the parent so it is visible in the activity feed
            # rather than living only in a log line that rotates.
            logger.error(
                "senaite_promote_writeback_failed parent=%s keyword=%s: the Mk1 "
                "promotion stands, SENAITE's line is now behind: %s",
                parent_sample_id, parent_row.keyword, e,
            )
            _sync_event = ("senaite_promote_writeback_failed", {
                "keyword": parent_row.keyword,
                "error": str(e)[:500],
                "reason": "SENAITE unreachable or refused — Mk1 promotion committed, mirror lagging",
            })
    else:
        logger.info(
            "native_promote_writeback_skipped parent_analysis_id=%s service_id=%s keyword=%s",
            parent_row.id, parent_row.analysis_service_id, parent_row.keyword,
        )

    if _sync_event is not None:
        # Its own transaction: the promotion is committed and must not be put
        # at risk by the bookkeeping that records how the tee went.
        try:
            from models import LimsSubSampleEvent
            db.add(LimsSubSampleEvent(
                lims_sample_pk=parent_row.lims_sample_pk,
                event=_sync_event[0],
                details=_sync_event[1],
                user_id=user_id,
            ))
            db.commit()
        except Exception:
            db.rollback()
            logger.exception(
                "promote_sync_event_write_failed parent=%s keyword=%s event=%s",
                parent_sample_id, parent_row.keyword, _sync_event[0],
            )

    _run_cascade(background_tasks, parent_row.lims_sample_pk, user_id)

    return PromoteResponse(
        parent=AnalysisResponse.model_validate(parent_row),
        promotions=[PromotionRow.model_validate(p) for p in promotion_rows],
    )
```

```python
def normalize_unit(unit: Optional[str]) -> str:
    """A unit as specs and results compare it (endo slice 3, spec section 6):
    trimmed, lower case, None as "". "EU/Vial", " eu/vial " and "EU/vial"
    are one unit, and so are NULL and "". The spec uniqueness indexes key on
    the same normalization (lower(btrim(coalesce(unit, ''))))."""
    return (unit or "").strip().lower()


def effective_unit(result_unit: Optional[str], service_unit: Optional[str]) -> str:
    """The normalized unit a result is judged in: its own, else its
    service's catalog unit (a vial row carries none until promote stamps
    one). A blank or whitespace-only result unit counts as none."""
    return normalize_unit(result_unit) or normalize_unit(service_unit)


def _first_in_scope(rows, matrix: Optional[str], peptide_id: Optional[int]):
    """The precedence over already-loaded active rows: (peptide) ->
    (matrix) -> (wildcard) -> None. Two rows in the winning scope raise
    MultipleResultsFound, as scalar_one_or_none did."""
    scopes = []
    if peptide_id is not None:
        scopes.append(lambda s: s.peptide_id == peptide_id)
    if matrix is not None:
        scopes.append(lambda s: s.matrix == matrix)
    # CRITICAL: the wildcard scope also requires peptide_id IS NULL. Without
    # it, a peptide-bound row could masquerade as the default when no true
    # wildcard row exists for this service.
    scopes.append(lambda s: s.matrix is None and s.peptide_id is None)
    for in_scope in scopes:
        hits = [s for s in rows if in_scope(s)]
        if len(hits) > 1:
            raise MultipleResultsFound(
                f"{len(hits)} active specs in one scope for analysis service "
                f"{hits[0].analysis_service_id} (spec ids {[s.id for s in hits]})")
        if hits:
            return hits[0]
    return None


def resolve_spec(db: Session, service_id: int, matrix: Optional[str],
                 peptide_id: Optional[int] = None, unit: Optional[str] = None):
    """Active spec by precedence: (service, peptide) -> (service, matrix) ->
    (service, wildcard) -> None, over one query for the service's active rows.

    unit (endo slice 3, spec section 6) is the result's unit: callers pass
    effective_unit(result_unit, service unit). When any active row of the
    service is filed in that unit, only those rows count and the first scope
    holding one wins: a new EU/vial result for a peptide whose per-peptide
    row is EU/mL falls through to the Peptide EU/vial row, and a bac water
    EU/mL result can never reach 350 EU/vial. When none is, today's lookup
    runs only for a result in the service's own catalog unit (or in none),
    so a spec filed as "µg/g", or with no unit, keeps judging the "ppm" or
    "Pos/Neg" results it judges today. A result in any other unit resolves
    None, and the certificate stops rather than judge it in another unit.
    unit=None is today's lookup.

    Two active rows in the winning scope raise MultipleResultsFound (the
    scalar_one_or_none behaviour this replaced). The partial unique indexes
    allow one active row per scope and unit, so a lookup without a unit
    that meets a scope holding two units fails loud (aborting the
    certificate) rather than silently picking a limit.

    peptide_id=None (the default, preserving every pre-slice-2 caller) skips
    tier 1 entirely. R4/R5: an unresolved peptide anchor, a blend (multiple
    distinct peptide anchors) or a non-peptide sample coarsens straight to
    matrix/wildcard and never aborts here."""
    from models import AnalysisService, AnalysisServiceSpec

    rows = db.execute(
        select(AnalysisServiceSpec).where(
            AnalysisServiceSpec.analysis_service_id == service_id,
            AnalysisServiceSpec.active.is_(True),
        ).order_by(AnalysisServiceSpec.id)
    ).scalars().all()
    if unit is not None:
        want = normalize_unit(unit)
        in_unit = [s for s in rows if normalize_unit(s.unit) == want]
        if in_unit:
            return _first_in_scope(in_unit, matrix, peptide_id)
        svc = db.get(AnalysisService, service_id)
        if want and want != normalize_unit(svc.unit if svc is not None else None):
            return None
    return _first_in_scope(rows, matrix, peptide_id)
```

```python
def effective_loq(row, spec) -> Optional[float]:
    """The LOQ a result is reported against (endo slice 3, spec section 7):
    the result's own (lims_analyses.loq, filled by the worksheet promote)
    when it carries one, else the spec row's. Heavy metals carry none, so
    theirs stays the spec's."""
    loq = row.loq if row.loq is not None else spec.loq
    return float(loq) if loq is not None else None


def _result_display(spec, result, loq: Optional[float]) -> Optional[str]:
    """Mk1's applied lab-reporting convention for the PRINTED result; the
    verdict never reads it. Only convention today: LOQ censoring on range
    rows, against the effective LOQ (effective_loq). Runs after evaluate(),
    which guarantees a finite numeric for range rows; the guards here are
    belt-and-braces, not policy."""
    if spec.rule_kind != "range" or loq is None:
        return None
    try:
        value = float(str(result or "").strip())
    except ValueError:
        return None
    if not math.isfinite(value):
        return None
    # At-or-below the LOQ prints "< LOQ" (Handler ruling 2026-09-14: a result
    # reported AT the LOQ is the reporting floor, not a quantified figure,
    # Endotoxin USP85 2.50 vs LOQ 2.5). The verdict still uses the raw number.
    # A "<25 EU/vial" result is stored as 25 with LOQ 25 (endo slice 3).
    return "< LOQ" if value <= loq else None
```

```python
    native endotoxin service by default) in `state`, and the row's reading
    saved with its cartridge, as the item PATCH and the reader import store
    them. The parent is the id before -S; it is made on first use."""
    parent_id, n = sample_id.rsplit("-S", 1)
    parent = db.execute(select(LimsSample).where(LimsSample.sample_id == parent_id)).scalar_one_or_none()
    if parent is None:
        parent = LimsSample(sample_id=parent_id, external_lims_uid=f"SEN-{parent_id}",
                            sample_type_title=sample_type)
        db.add(parent)
        db.flush()
    vial = LimsSubSample(sample_id=sample_id, parent_sample_pk=parent.id, vial_sequence=int(n),
                         external_lims_uid=f"mk1://{sample_id}", assignment_role=role)
    db.add(vial)
    db.flush()
    svc = service or w.svc
    analysis = LimsAnalysis(lims_sub_sample_pk=vial.id, analysis_service_id=svc.id,
                            keyword=svc.keyword, title=svc.title, review_state=state,
                            provenance="canonical")
    item = WorksheetItem(worksheet_id=(ws or w.ws).id, sample_uid=vial.external_lims_uid,
                         sample_id=sample_id, result_reading=reading,
                         cartridge_type_id=(cartridge or w.c05).id if reading else None,
                         result_reader=reader, prep_total_dilution=total)
    db.add_all([analysis, item])
    db.flush()
    return item, analysis


def _imported(test_id, result, **over):
    """A stored reader record for `result`, in the reader import's shape."""
    return {**_record(test_id=test_id), "result": result, "valid": True, "why": [], **over}


def _line(item, value=25, *, unit="EU/vial", loq=25, lod=0.05, lod_unit="EU/mL"):
    """One ticked row as the confirm dialog sends it. The default is a
    peptide "<0.05" on the 0.05 cartridge at the standard 2 mL and 1:250:
    <25 EU per vial (0.05 x 250 x 2), sent as 25 with LOQ 25 and LOD 0.05."""
    return {"item_id": item.id, "value": value, "unit": unit, "loq": loq, "lod": lod,
            "lod_unit": lod_unit}


def _promote(client, ws, *lines):

def _results(r):

def _refused(item, reason):
    return {"item_id": item.id, "promoted": False, "parent_analysis_id": None, "state": None,

def _parent_rows(db, parent_sample_id):
    db.expire_all()

        LimsAnalysis.lims_sample_pk == parent.id, LimsAnalysis.lims_sub_sample_pk.is_(None))
        .order_by(LimsAnalysis.id)).scalars().all()
```

```python
"""Promote to Parent from the 2 mL endotoxin worksheet (endo slice 3, spec
docs/superpowers/specs/2026-10-12-endo-slice3-promote-loq-design.md, sections
5.2 and 5.3).

The browser sends the values the analyst sees: the value, its unit, its LOQ,
its LOD and the LOD's unit (spec D6). The server re-checks every eligibility
rule from what the worksheet stored, fills the vial's endotoxin result,
promotes it through the sample page's own promote function
(lims_analyses.promote_flow.run_promote) and records where each value came
from. It never recomputes the endotoxin maths.

Rows are independent: a row's fill and promote commit together or not at
all, and a refused or failed row never blocks the others."""
import logging
import math
import re
from decimal import Decimal
from types import SimpleNamespace
from typing import Optional

from pydantic import BaseModel, Field
from sqlalchemy import select
from sqlalchemy.orm import Session

from coa.spec_rules import normalize_matrix, normalize_unit, resolve_spec, sample_peptide_id
from models import (
    AnalysisService, AuditLog, LimsAnalysis, LimsSample, LimsSubSample, WorksheetItem,
)
from worksheets_endo import (
    ENDO_FORMS, cartridge_sensitivities, endo_run_params, parse_reading, reader_shows,
    reader_validity, resolve_endo_method,
)

log = logging.getLogger(__name__)

UNIT_PEPTIDE = "EU/vial"
UNIT_BAC = "EU/mL"
LOD_UNIT = "EU/mL"
# Bac water goes into the cartridge 20x, so a clean run reads < sensitivity
# x 20 (src/lib/endo-prep-2ml.ts BW_DILUTION and prep2Check's floorShown).
BW_DILUTION = 20
# The words of the browser's isBacWater (src/lib/endo-prep.ts).
_BAC_WORDS = re.compile(r"bacteriostatic|bac\.?\s*water", re.IGNORECASE)
# Dead rows never speak for a vial (worksheets_endo._DEAD_STATES).
_DEAD_STATES = ("rejected", "retracted")
# The vial states a worksheet may fill (spec 5.2 rule 2).
_FILLABLE_STATES = ("unassigned", "assigned", "to_be_verified")

# Spec 5.3's reasons; the dialog shows them as they are.
REASON_STOCK = "promote is for 2 mL worksheets"
REASON_NOT_ON_WORKSHEET = "not on this worksheet"
REASON_NOT_NATIVE = "manual entry: SENAITE-born endotoxin"
REASON_NO_ENDO = "the vial has no endotoxin analysis"
REASON_MANY_ENDO = "the vial has more than one endotoxin analysis"
REASON_PROMOTED = "already promoted"
REASON_PARENT_HOLDS = "the parent already holds a result; retest the vial to replace it"
REASON_NO_READING = "no reading"
REASON_NO_CARTRIDGE = "the row has no cartridge"
REASON_PEPTIDE_UNIT = "peptides promote in EU/vial"
REASON_BAC_UNIT = "bac water promotes in EU/mL"
REASON_BAD_NUMBERS = "the value, LOQ or LOD does not match the worksheet row"
REASON_UNEXPECTED = "not promoted: an unexpected error, see the server log"
TYPED = "typed, no reader record"


class EndoPromoteRowIn(BaseModel):
    """One ticked Box 3 row: the values its confirm dialog showed."""
    item_id: int
    value: float
    unit: str
    loq: float
    lod: float
    lod_unit: str


class EndoPromoteRequest(BaseModel):
    # The reader import's bound; the route also caps it at the item count.
    rows: list[EndoPromoteRowIn] = Field(max_length=500)


class EndoPromoteRowResult(BaseModel):
    item_id: int
    promoted: bool
    parent_analysis_id: Optional[int] = None
    state: Optional[str] = None
    reason: Optional[str] = None

    results: list[EndoPromoteRowResult]


class _Refused(Exception):
    """A row that cannot be promoted; the message is the reason shown."""


def vial_endo_analyses(db: Session, sample_ids) -> dict[str, list[tuple[LimsAnalysis, AnalysisService]]]:
    """Each vial's live endotoxin analyses with their services (spec 5.2
    rule 1), keyed by the vial's sample id: the current row of each retest
    chain (retested is false), not rejected or retracted, on a service whose
    keyword names the endotoxin bench (main._bench_kind_for_keyword; the
    service FK, never the row's label). ONE query for any number of vials,
    never one per item (the 2026-09-15 pool outage class). A sample id with
    no vial (a legacy bare parent id) maps to an empty list."""
    out: dict = {sid: [] for sid in sample_ids}
    if not out:
        return out
    from main import _bench_kind_for_keyword  # lazy: main imports this module

    for sample_id, analysis, svc in db.execute(
        select(LimsSubSample.sample_id, LimsAnalysis, AnalysisService)
        .join(LimsAnalysis, LimsAnalysis.lims_sub_sample_pk == LimsSubSample.id)
        .join(AnalysisService, AnalysisService.id == LimsAnalysis.analysis_service_id)
        .where(LimsSubSample.sample_id.in_(list(out)),
               LimsAnalysis.retested.is_(False),
               LimsAnalysis.review_state.notin_(_DEAD_STATES))
        .order_by(LimsAnalysis.id)
    ).all():
        if _bench_kind_for_keyword(svc.keyword) == "endo":
            out[sample_id].append((analysis, svc))
    return out


def endo_analysis_by_sample(db: Session, sample_ids) -> dict[str, Optional[dict]]:
    """The endo_analysis key of endotoxin worksheet items (spec 5.1): the
    vial's one live endotoxin analysis as {id, state, keyword, native}, else
    None (no vial, no live endotoxin analysis, or more than one; the
    promote's refusal tells those apart). One query for a whole page."""
    out: dict[str, Optional[dict]] = {}
    for sample_id, pairs in vial_endo_analyses(db, sample_ids).items():
        if len(pairs) != 1:
            out[sample_id] = None
            continue
        analysis, svc = pairs[0]
        out[sample_id] = {"id": analysis.id, "state": analysis.review_state,
                          "keyword": svc.keyword, "native": svc.origin == "mk1"}
    return out


def _same(a: float, b: float) -> bool:
    """Equal within the spec's relative tolerance (1e-9)."""
    return math.isclose(a, b, rel_tol=1e-9)


def _num_text(v: float) -> str:
    """A result as stored text, never in exponent form (main._dec_to_str's
    idiom): 25.0 -> "25", 350.0 -> "350", 0.2 -> "0.2"."""
    return format(Decimal(repr(v)).normalize(), "f")


def _positive(v) -> Optional[float]:
    """A catalog sensitivity as a usable number (consumable specs are free
    JSON), else None."""
    ok = (isinstance(v, (int, float)) and not isinstance(v, bool)
          and math.isfinite(v) and v > 0)
    return float(v) if ok else None


def _is_bac(item, parent) -> bool:
    """The row's form as the browser's formOf reads it (v2 spec 4.2): a form
    set on the row wins; otherwise a BW- sample id, or a sample type or
    identity that mentions bacteriostatic water, from the same parent facts
    the worksheet item serves."""
    if item.prep_form in ENDO_FORMS:
        return item.prep_form == "bac"
    from main import _worksheet_item_parent_facts  # lazy: main imports this module

    facts = _worksheet_item_parent_facts(parent)
    return ((item.sample_id or "").upper().startswith("BW-")
            or bool(_BAC_WORDS.search(facts["sample_type"] or ""))
            or bool(_BAC_WORDS.search(facts["sample_identity"] or "")))


def _parent_holds(db: Session, parent_pk: int, service_id: int) -> bool:
    """The parent already holds a live result for this service: the row
    uq_lims_analyses_parent_service_id_root keeps unique (database.py)."""
    return db.execute(select(LimsAnalysis.id).where(
        LimsAnalysis.lims_sample_pk == parent_pk,
        LimsAnalysis.lims_sub_sample_pk.is_(None),
        LimsAnalysis.analysis_service_id == service_id,
        LimsAnalysis.provenance == "canonical",
        LimsAnalysis.retest_of_id.is_(None),
        LimsAnalysis.review_state.notin_(_DEAD_STATES),
    ).limit(1)).first() is not None


def _refusal(item_id: int, reason: str) -> EndoPromoteRowResult:
    return EndoPromoteRowResult(item_id=item_id, promoted=False, reason=reason)


def _plan(db: Session, worksheet, item, row: EndoPromoteRowIn, ctx) -> dict:
    """Spec 5.2's rules re-checked from stored data, in the order of spec
    5.3's reason table where one rule needs another's answer, then the spec
    the result will be judged by. Writes nothing. Returns what the fill, the
    promote and the audit row need, or raises _Refused with the reason."""
    if item is None:
        raise _Refused(REASON_NOT_ON_WORKSHEET)
    pairs = ctx.live.get(item.sample_id) or []
    if not pairs:
        raise _Refused(REASON_NO_ENDO)
    if len(pairs) > 1:
        raise _Refused(REASON_MANY_ENDO)
    analysis, svc = pairs[0]
    if svc.origin != "mk1":
        raise _Refused(REASON_NOT_NATIVE)
    if analysis.review_state == "promoted":
        raise _Refused(REASON_PROMOTED)
    if analysis.review_state not in _FILLABLE_STATES:
        raise _Refused(f"the vial's endotoxin analysis is {analysis.review_state}")
    parent = ctx.parents[ctx.parent_pk_by_sample[item.sample_id]]
    # Only a retest row's promote may supersede the parent's live result
    # (promote_to_parent); any other row would collide with it.
    if analysis.retest_of_id is None and _parent_holds(db, parent.id, svc.id):
        raise _Refused(REASON_PARENT_HOLDS)
    if item.result_reading is None:
        raise _Refused(REASON_NO_READING)
    lt, reading = parse_reading(item.result_reading)
    record = item.result_reader
    if record:
        valid, why = reader_validity(record, ctx.run_params)
        if not valid:
            raise _Refused("Invalid: " + "; ".join(why))
    bac = _is_bac(item, parent)
    unit = UNIT_BAC if bac else UNIT_PEPTIDE
    if normalize_unit(row.unit) != normalize_unit(unit):
        raise _Refused(REASON_BAC_UNIT if bac else REASON_PEPTIDE_UNIT)
    # A saved reading always stores its row's cartridge (check_item_endo_fields);
    # the run's and the method default are the spec's fallbacks.
    cartridge_id = (item.cartridge_type_id or worksheet.cartridge_type_id
                    or ctx.default_cartridge_id)
    sensitivity = _positive(ctx.sensitivities.get(cartridge_id))
    if sensitivity is None:
        raise _Refused(REASON_NO_CARTRIDGE)
    # The number a clean run shows: the sensitivity, x 20 for bac water.
    floor = round(sensitivity * BW_DILUTION, 6) if bac else sensitivity
    if lt and not _same(reading, floor):
        what = "floor for bac water" if bac else "sensitivity"
        raise _Refused(f"the reading <{reading:g} is not this cartridge's {what} ({floor:g})")
    if (not all(math.isfinite(x) for x in (row.value, row.loq, row.lod))
            or row.value < 0 or row.loq <= 0 or row.lod <= 0
            or normalize_unit(row.lod_unit) != normalize_unit(LOD_UNIT)
            or not _same(row.lod, sensitivity)
            or (lt and not _same(row.value, row.loq))):
        raise _Refused(REASON_BAD_NUMBERS)
    # The spec the certificate will judge the result by (coa.native_sections).
    matrix = normalize_matrix(parent.sample_type_title)
    spec = resolve_spec(db, svc.id, matrix, peptide_id=sample_peptide_id(db, parent.id),
                        unit=unit)
    if spec is None:
        raise _Refused(f"No active {svc.title} spec in {unit} for {matrix or 'any sample type'}")
    limit = (float(spec.max_value)
             if spec.rule_kind == "range" and spec.max_value is not None else None)
    if lt and limit is not None and row.loq > limit:
        raise _Refused(f"inconclusive: LOQ {row.loq:g} {unit} is above the {limit:g} limit")
    # A "<" result is stored as the number equal to its LOQ (spec section 4),
    # the same float, so the certificate's value <= LOQ always prints "< LOQ".
    loq = row.value if lt else row.loq
    params = endo_run_params(ctx.run_params)
    if bac:
        total, water = BW_DILUTION, None
    else:
        total = (item.prep_total_dilution if (item.prep_total_dilution or 0) > 0
                 else params["std_total_dilution"])
        water = (item.prep_water_ml if (item.prep_water_ml or 0) > 0
                 else None if item.prep_form == "liquid" else params["recon_water_ml"])
    return {
        "analysis": analysis,
        "unit": unit,
        "loq": loq,
        "details": {
            "user_id": ctx.user_id, "worksheet_id": worksheet.id, "item_id": item.id,
            "sample_id": item.sample_id, "reading": item.result_reading,
            "reader_test_id": (record.get("test_id")
                               if record and reader_shows(record, (lt, reading)) else TYPED),
            "cartridge_type_id": cartridge_id, "cartridge_sensitivity": sensitivity,
            "total_dilution": total, "water_ml": water,
            "value": row.value, "unit": unit, "loq": loq, "lod": row.lod, "lod_unit": LOD_UNIT,
        },
    }


def _promote_one(db: Session, current_user, worksheet, item, row: EndoPromoteRowIn, plan: dict,
                 background_tasks) -> EndoPromoteRowResult:
    """Fill the vial's result and promote it (spec 5.3 steps 2 to 4). The
    fill is flushed into the transaction run_promote commits, so the two land
    together or not at all. The provenance row needs the parent's id, so it
    follows in its own commit; a failure there is logged and the promotion
    stands, as the sample page's promote treats its own bookkeeping."""
    from lims_analyses import promote_flow  # lazy, so a test can patch run_promote
    from lims_analyses.schemas import PromoteRequest, PromoteSourceRef
    from lims_analyses.service import apply_transition

    analysis = plan["analysis"]
    value = _num_text(row.value)
    reason = f"promoted from worksheet WS-{worksheet.id} row {item.sample_id}"
    # The worksheet's pinned endotoxin method (v2 pins it at the first reading
    # or print); unpinned, the vial keeps the method it has.
    method_id = worksheet.endo_method_id or analysis.method_id
    apply_transition(
        db, analysis_id=analysis.id, kind="submit", result_value=value,
        result_unit=plan["unit"], loq=plan["loq"], lod=row.lod, lod_unit=LOD_UNIT,
        method_id=method_id, user_id=plan["details"]["user_id"], reason=reason, commit=False,
    )
    resp = promote_flow.run_promote(db, current_user, PromoteRequest(
        keyword=analysis.keyword, result_value=value, result_unit=plan["unit"],
        method_id=method_id,
        # The instrument the reader import stamped stays as it is.
        instrument_id=analysis.instrument_id,
        sources=[PromoteSourceRef(analysis_id=analysis.id, contribution_kind="chosen")],
        reason=reason, loq=plan["loq"], lod=row.lod, lod_unit=LOD_UNIT,
    ), background_tasks=background_tasks, audit_reason=reason)
    parent_id = resp.parent.id
    try:
        db.add(AuditLog(operation="endo_worksheet_promoted", entity_type="lims_analysis",
                        entity_id=str(parent_id), details=plan["details"]))
        db.commit()
    except Exception:
        db.rollback()
        log.exception("endo_worksheet_promote_audit_failed worksheet=%s item=%s parent_analysis=%s",
                      plan["details"]["worksheet_id"], plan["details"]["item_id"], parent_id)
    return EndoPromoteRowResult(item_id=row.item_id, promoted=True,
                                parent_analysis_id=parent_id, state=resp.parent.review_state)


def promote_rows(db: Session, current_user, worksheet, rows: list[EndoPromoteRowIn], *,
                 background_tasks=None) -> list[EndoPromoteRowResult]:
    """POST /worksheets/{id}/promote's rows, each answered on its own and in
    the order sent (spec 5.3). The route has already refused a malformed
    body. A stock worksheet refuses every row. The worksheet's stored data is
    read in a fixed number of queries; each eligible row then costs its own
    checks, writes and commit."""
    if worksheet.endo_prep != "2ml":
        return [_refusal(r.item_id, REASON_STOCK) for r in rows]
    from lims_analyses.promote_flow import PromoteError
    from lims_analyses.state_machine import InvalidTransitionError

    ws_id = worksheet.id
    items = {it.id: it for it in db.execute(
        select(WorksheetItem).where(WorksheetItem.worksheet_id == ws_id)).scalars()}
    sample_ids = {it.sample_id for it in items.values() if it.sample_id}
    parent_pk_by_sample = dict(db.execute(
        select(LimsSubSample.sample_id, LimsSubSample.parent_sample_pk)
        .where(LimsSubSample.sample_id.in_(sample_ids))).all()) if sample_ids else {}
    parents = {p.id: p for p in db.execute(select(LimsSample).where(
        LimsSample.id.in_(set(parent_pk_by_sample.values())))).scalars()} if parent_pk_by_sample else {}
    method = resolve_endo_method(db, worksheet)
    default_cartridge_id = next(
        (c["id"] for c in (method["cartridges"] if method else []) if c["is_default"]), None)
    cartridge_ids = ({it.cartridge_type_id for it in items.values()}
                     | {worksheet.cartridge_type_id, default_cartridge_id}) - {None}
    ctx = SimpleNamespace(
        user_id=getattr(current_user, "id", None),
        live=vial_endo_analyses(db, sample_ids),
        parent_pk_by_sample=parent_pk_by_sample,
        parents=parents,
        run_params=method["run_parameters"] if method else None,
        default_cartridge_id=default_cartridge_id,
        sensitivities=cartridge_sensitivities(db, cartridge_ids),
    )
    results = []
    for row in rows:
        try:
            item = items.get(row.item_id)
            plan = _plan(db, worksheet, item, row, ctx)
            results.append(_promote_one(db, current_user, worksheet, item, row, plan,
                                        background_tasks))
        except _Refused as refused:
            db.rollback()
            results.append(_refusal(row.item_id, str(refused)))
        except PromoteError as e:
            # The parent's unique index on Postgres: two requests raced past the checks.
            db.rollback()
            results.append(_refusal(row.item_id, REASON_PARENT_HOLDS
                                    if e.code == "parent_row_already_exists" else str(e.detail)))
        except InvalidTransitionError as e:
            # The vial moved between the check and the fill (another tab promoted it).
            db.rollback()
            results.append(_refusal(row.item_id, REASON_PROMOTED
                                    if e.from_state == "promoted" else str(e)))
        except Exception:
            db.rollback()
            log.exception("endo_worksheet_promote_failed worksheet=%s item=%s", ws_id, row.item_id)
            results.append(_refusal(row.item_id, REASON_UNEXPECTED))
    return results
```

```ts
/**
 * Promote to Parent from Box 3 (spec 2026-10-12 sections 5.2 and 5.3): may
 * this row be promoted, and the numbers it sends. The server re-checks every
 * rule from stored data and stays the authority; this mirrors it, in the
 * same order and with the server's own reason texts, so a row it would
 * refuse is never ticked. The server alone knows whether the parent already
 * holds a result. Pure.
 */
import type { EndoPromoteRowIn, WorksheetListItem } from '@/lib/api'
import { fmt } from '@/lib/endo-prep'
import {
  BW_LIMIT_EU_PER_ML,
  LIMIT_EU_PER_VIAL,
  fmtEu,
  formOf,
  isBacWaterSample,
  prep2Check,
  prep2Result,
  type EndoCtx,
} from '@/lib/endo-prep-2ml'
import type { EndoRow } from '@/lib/endo-worksheet-2ml'

export type PromoteCheck =
  | { eligible: true; payload: EndoPromoteRowIn }
  | { eligible: false; reason: string }
  | { promoted: true }

/** The Mk1-native endotoxin service; SENAITE-born ENDO-LAL keeps manual entry (D2). */
const NATIVE_ENDO_KEYWORD = 'ENDOTOXIN-USP85LAL'
const OPEN_STATES = ['unassigned', 'assigned', 'to_be_verified']
/** Box 3 shows no checkbox at all for these rows (spec 5.1). */
export const SENAITE_BORN = 'manual entry: SENAITE-born endotoxin'

const no = (reason: string): PromoteCheck => ({ eligible: false, reason })

/** The number as Box 3 shows it (3 decimals): what the analyst sees is sent (D6). */
const shown = (v: number): number => Number(fmt(v))

/**
 * Spec 5.2's rules in order: one live native endotoxin analysis, an open
 * state, a reading, not Invalid, not inconclusive, a "<" reading on the
 * row's floor, the unit the sample's form allows, then usable numbers. A "<"
 * result sends its LOQ as its value (the same number, so the server's
 * value == loq check holds exactly); `lod` is the row's cartridge
 * sensitivity as stored, never rounded.
 */
export function promoteCheck(
  row: EndoRow,
  ctx: EndoCtx,
  endoPrep: WorksheetListItem['endo_prep']
): PromoteCheck {
  if (endoPrep !== '2ml') return no('promote is for 2 mL worksheets')
  const a = row.item.endo_analysis
  if (!a) return no('the vial has no endotoxin analysis')
  if (!a.native || a.keyword !== NATIVE_ENDO_KEYWORD) return no(SENAITE_BORN)
  if (a.state === 'promoted') return { promoted: true }
  if (!OPEN_STATES.includes(a.state))
    return no(`the vial's endotoxin analysis is ${a.state}`)
  const s = row.sample
  const rs = prep2Result(s, ctx)
  if (rs.value === null) return no('no reading')
  if (rs.verdict === 'invalid')
    return no(`Invalid: ${(s.reader?.why ?? []).join('; ')}`)
  const k = prep2Check(s, ctx)
  const bac = formOf(s) === 'bac'
  const unit = bac ? 'EU/mL' : 'EU/vial'
  const raw = bac ? rs.value : rs.euPerVial
  const value = raw === null ? null : shown(raw)
  const loqRaw = bac ? k.loqMl : k.loqVial
  const loq = rs.lt ? value : loqRaw === null ? null : shown(loqRaw)
  if (rs.verdict === 'inconclusive')
    return no(
      `inconclusive: LOQ ${fmt(loq)} ${unit} is above the ${fmt(bac ? BW_LIMIT_EU_PER_ML : LIMIT_EU_PER_VIAL)} limit`
    )
  if (rs.floorMismatch)
    return no(
      `the reading ${fmtEu(true, rs.value)} is not this cartridge's ${bac ? 'floor for bac water' : 'sensitivity'} (${fmt(rs.expectedFloor)})`
    )
  if (bac !== isBacWaterSample(s))
    return no(
      bac ? 'peptides promote in EU/vial' : 'bac water promotes in EU/mL'
    )
  const lod = row.cartridge?.sensitivity ?? null
  if (lod === null) return no('the row has no cartridge')
  if (
    (rs.verdict !== 'pass' && rs.verdict !== 'fail') ||
    value === null ||
    loq === null ||
    lod === null ||
    !(value >= 0 && loq > 0 && lod > 0)
  )
    return no('the value, LOQ or LOD does not match the worksheet row')
  return {
    eligible: true,
    payload: {
      item_id: row.item.id,
      value,
      unit,
      loq,
      lod,
      lod_unit: 'EU/mL',
    },
  }
}
```

```tsx
export interface PromotePick {

  payload: EndoPromoteRowIn
  verdict: { label: string; tone: string }

const PCELL = 'border-b border-border/60 px-2 py-1.5 align-top'

function Outcome({ result }: { result: EndoPromoteRowResult | undefined }) {
  if (!result)
    return <span className="text-muted-foreground">no reply for this row</span>
  if (!result.promoted)
    return (
      <span className="text-red-600 dark:text-red-400">

  const state = result.state

      {state
        ? `: parent result ${labelFor(state, STATE_LABELS[state]?.label ?? state, 'analysis')}`
        : ''}
    </span>
  )
}

/**
 * Box 3's Promote to Parent (spec 5.1): the button, a confirm listing each
 * ticked row with exactly what is sent, one request, then each row's
 * outcome. The list is the picks as they were when it opened, so the
 * refresh after a promote never rewrites it under its results.
 */
export function EndoPromoteDialog({
  worksheetId,
  picks,
  onSettled,
}: {
  worksheetId: number
  /** The ticked rows that are eligible now, in Box 3 order. */
  picks: PromotePick[]
  /** After the server replied (true) or the request failed (false). */
  onSettled: (replied: boolean) => void
}) {
  const [listed, setListed] = useState<PromotePick[] | null>(null)
  const [results, setResults] = useState<Map<
    number,
    EndoPromoteRowResult
  > | null>(null)
  const [sending, setSending] = useState(false)
  const [error, setError] = useState<string | null>(null)

  function close() {
    setListed(null)
    setResults(null)
    setError(null)
  }

  async function send() {
    if (!listed?.length || sending) return
    setSending(true)
    setError(null)
    try {
      const res = await promoteWorksheetRows(
        worksheetId,
        listed.map(p => p.payload)
      )
      setResults(new Map(res.results.map(r => [r.item_id, r])))
      onSettled(true)
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Promote failed')
      onSettled(false)
    } finally {
      setSending(false)
    }
  }

  const done = results
    ? [...results.values()].filter(r => r.promoted).length
    : 0

  return (
    <>
      <Button
        size="sm"
        className="shrink-0"
        disabled={!picks.length}
        onClick={() => setListed(picks)}
      >
        Promote to Parent ({picks.length})
      </Button>
      <Dialog
        open={listed !== null}
        onOpenChange={open => {
          if (!open && !sending) close()
        }}
      >
        {listed && (
          <DialogContent className="flex max-h-[88vh] w-[820px] max-w-[96vw] flex-col gap-3 sm:max-w-[96vw]">
            <DialogTitle className="text-sm font-semibold">
              Promote to Parent
            </DialogTitle>
            <DialogDescription className="text-xs">
              {results
                ? `${done} of ${listed.length} promoted. A reviewer verifies each parent result on its sample page.`
                : "Fills each vial's endotoxin result with these values and promotes it to its parent sample, where a reviewer verifies it. A < result is sent as its LOQ; the COA prints it as < LOQ."}
            </DialogDescription>
            <div className="min-h-0 overflow-auto">
              <table className="w-full border-collapse text-[12.5px]">
                <thead>
                  <tr>
                    <th className={TH}>Row</th>
                    <th className={TH}>Sample ID</th>
                    <th className={`${TH} !text-right`}>Value</th>
                    <th className={`${TH} !text-right`}>LOQ</th>
                    <th className={`${TH} !text-right`}>LOD</th>
                    <th className={TH}>Verdict</th>

                      </td>

                        {payload.value} {payload.unit}
                      </td>
                      <td className={`${PCELL} text-right font-mono`}>
                        {payload.loq} {payload.unit}
                      </td>
                      <td className={`${PCELL} text-right font-mono`}>
                        {payload.lod} {payload.lod_unit}
                      </td>
```
